# Streaming binaries (auto-downloaded)

This folder holds `N_m3u8DL-RE.exe` and `ffmpeg.exe`.

They are **not** committed to GitHub (large binaries). When you run OmniStream Pro, missing tools are downloaded automatically into:

- `desktop/bin/` (source / portable build)
- or `%LOCALAPPDATA%\OmniStreamPro\bin\` (installed app)

You can also place the executables here manually before building a release.
